## 📌 녹화 시 참고사항
1. **LINER 3종 API 가동 현황**: 사이드바 하단의 호출 카운터가 동작하는 모습을 자연스럽게 보여줄 것.
2. **산출물 다운로드 확인**: `1-Page 전환 이력서 (.html)`와 `면접관 채점표 (.html)` 파일이 정상 생성되는 모습을 시연할 것.
3. **단정적 표현 자제**: AI가 합격/불합격을 결정하는 것이 아니라 면접관의 검증을 돕는 보조 도구임을 명확히 할 것.
